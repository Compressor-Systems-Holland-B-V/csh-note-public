Privacy policy

znote · last updated 14 October 2026

znote itself collects nothing: no accounts, no analytics, no advertising, no tracking and no crash reports. ZAL Analytics runs no server that the app talks to. Your documents leave your computer only when you use the assistant, and then only to the provider you chose.

What the app stores

Your projects, notebooks and pages, your settings, the themes you installed and your assistant chats are saved in the app's own data folder on your computer. A .znote file you save or open is written to or read from the place you pick. None of this is uploaded by znote.

Keys for assistant providers, such as an OpenRouter key or the key of a server you run yourself, are kept in your operating system's password store (Windows Credential Manager, the macOS Keychain, or GNOME Keyring or KWallet on Linux). They are only sent to the provider they belong to, and never written to a settings file or a log.

What leaves your computer

znote works offline. It goes online only in these cases:

  • Typst packages. When a document imports a package such as @preview/name:1.0.0 that is not on your computer yet, znote downloads it from packages.typst.org, the official Typst package registry.
  • The theme store. When you open the theme store, znote reads the list of themes and downloads the ones you install from ZAL Analytics' public dataset on Hugging Face (huggingface.co/datasets/zal-analytics-core/znote-data).
  • The assistant, only if you set it up and use it. What you type, the chat so far, and the pages and files you attach or let the assistant read are sent to the provider you picked:
    • Claude: znote runs Anthropic's own Claude Code program, which you sign in to yourself. Claude Code sends your requests to Anthropic. If it is not installed yet, znote downloads Anthropic's installer from claude.ai when you press Connect. znote never reads or stores your Claude sign-in.
    • OpenRouter: requests go to openrouter.ai with your own key.
    • Your own server, such as Ollama: requests go only to the address you entered.
    Each provider handles your data under its own privacy policy.
  • Web pages for the assistant, only if you allow internet use in a chat. The assistant can then read public https:// pages. With OpenRouter or your own server, znote fetches the page itself and refuses addresses on your local network. With Claude, Claude Code's own web tools are used.

These requests carry nothing about you beyond what is listed above. Like any web server, each service sees the IP address a request comes from.

Children

znote is a general purpose writing tool and collects no personal data from anyone, children included.

Changes

If this policy changes, the updated version is posted on this page with a new date above. The app is open source, so any change to what it does with your data is visible in its history.
